# CV Home — design mockup

A standalone HTML prototype of the planned Home page (CV introduction) and the
global one-line weather strip. **Nothing here ships** — it is a design-review
artifact that exists so the layout and motion can be confirmed before `src/` is
touched. No build step, no dependency on the React app.

Open [index.html](index.html) directly in a browser to click through the expand
and scroll animations.

## Query flags

The page reads a few URL flags so screenshots can capture specific states:

| Flag | Effect |
| --- | --- |
| `?reveal=all` | Marks every scroll-reveal element visible immediately (needed for full-page captures, since off-screen elements never trigger their IntersectionObserver) |
| `?expand=all` | Opens every collapsible experience card |
| `?collapse=all` | Closes every collapsible experience card |

They combine: `index.html?reveal=all&expand=all`.

`playwright-core` is deliberately **not** a dependency of this app, so install
it somewhere scratch and point the script at it:

```
mkdir %TEMP%\pw && cd %TEMP%\pw && npm i playwright-core
set PLAYWRIGHT_CORE=%TEMP%\pw\node_modules\playwright-core\index.js
cd <repo>\docs\mockups\cv-home && node screenshots.mjs
```

It drives the locally installed Chrome via `channel: 'chrome'`, so there is no
browser download and nothing added to the app's `package.json`.

## What the mockup commits to

- Styling uses the tokens from [src/theme.js](../../../src/theme.js) directly
  (`#f8fafc` / `#ffffff` / `#e2e8f0` / `#1e293b` / `#64748b` / `#2563eb`,
  12px card radius, the MUI card shadow). No new palette.
- The navbar markup and CSS mirror [src/index.css](../../../src/index.css) so
  the weather strip can be judged in its real context.
- Content is transcribed from the résumé PDF. That PDF is a two-column
  layout, so the text was reassembled by glyph coordinates rather than
  reading order.

## Resolved

1. **Date on the strip** — removed. No clock or date anywhere.
2. **Location label** — comes from the API's `name`, not a constant. For the
   hardcoded coordinates in [src/App.js](../../../src/App.js) that field
   returns `"Zhuzilin"`, which is what the mockup and the shipped bar now
   show. Swapping it for a fixed `台北` is one line in
   [WeatherBar.js](../../../src/components/WeatherBar.js).
3. **Fonts** — unchanged. Chinese keeps the system fallback; no Noto Sans TC.

This mockup has been implemented. The live page is
[src/pages/home/Home.js](../../../src/pages/home/Home.js); content lives in
[cvData.js](../../../src/pages/home/cvData.js). Keep the two in sync when
either changes, or delete this folder once it stops being useful.
